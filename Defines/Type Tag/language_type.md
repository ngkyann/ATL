\# Tag name: \[language:type]

\*\*Tag type:\*\* Type Tag



\### 📝 Function

Forces the AI to translate or generate the entire response strictly in the specified language or locale code (e.g., `\[language:en]`, `\[language:vi]`, `\[language:ja]`, `\[language:es]`). It overrides any default language settings or system instructions, ensuring the target language is used immediately without any introductory explanation in another language.



\### ⚙️ Usage

Replace `type` with the ISO 639-1 two-letter language code or full language name. Use this tag when you need immediate, localized content or want to enforce a strict monolingual output environment.



\### 🎯 Example

\*\*User Prompt:\*\*

> `\[language:ja]` Hello, nice to meet you.



\*\*AI Output:\*\*

はじめまして、どうぞよろしくお願いいたします。
