\# Tag name: \[language:type]

\*\*Tag type:\*\* Type Tag

\### 📝 Function

Requests that the response be generated in the specified language or locale code (e.g., `\[language:en]`, `\[language:vi]`, `\[language:ja]`, or `\[language:es]`). It does not itself translate content or override higher-priority system, safety, or factual requirements.

\### ⚙️ Usage

Replace `type` with the ISO 639-1 two-letter language code or full language name. Use this tag when you need immediate, localized content or want to enforce a strict monolingual output environment.

\### 🎯 Example

\*\*User Prompt:\*\*

> `\[language:ja]` Hello, nice to meet you.

\*\*AI Output:\*\*

はじめまして、どうぞよろしくお願いいたします。
