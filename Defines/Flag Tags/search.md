\# Tag name: \[search]

\*\*Tag type:\*\* Flag Tag



\### 📝 Function

Instructs the AI to perform a real-time web search to fetch up-to-date information, completely bypassing or supplementing its pre-trained data repository.



\### ⚙️ Usage

Use this tag when your query requires the latest data, news, prices, or events that occurred after the AI's training cutoff date. Place it at the beginning or end of the prompt for best results.



\### 🎯 Example

\*\*User Prompt:\*\*

> `\[search]` What is the current price of gold today?



\*\*AI Output:\*\*

According to live market data updated 10 minutes ago, the current price of gold has increased by 0.5%...
