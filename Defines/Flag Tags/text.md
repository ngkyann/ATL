\# Tag name: \[text]

\*\*Tag type:\*\* Flag Tag



\### 📝 Function

Instructs the AI to output the response entirely in a standard, unformatted plain text format. It strictly prevents the model from generating code blocks, markdown elements (like tables, bolding, or headers), bold styles, or any structured objects.



\### ⚙️ Usage

Apply this tag when you need raw, clean text content that can be easily copied and pasted into simple text editors, terminal windows, or legacy systems without carrying over any markdown formatting artifacts.



\### 🎯 Example

\*\*User Prompt:\*\*

> `\[text]` Write a short welcome message for a website.



\*\*AI Output:\*\*

Welcome to our official website. We are dedicated to providing you with the best experience possible. Explore our services and stay updated with our latest news.
