\# Tag name \[result]

Tag type Flag Tag

\### 📝 Function

Requests a concise direct answer or final result. It asks the model to omit unnecessary step-by-step explanations, reasoning, formulas, and background information, while preserving any explanation that is required for safety or correctness.

\### ⚙️ Usage

Apply this tag when you need a quick, no-nonsense answer (like a mathematical solution, a specific fact, or a yesno response) and want to save tokens and reading time.

\### 🎯 Example

User Prompt

&#x20;`\[result]` What is the square root of 144

AI Output

12
