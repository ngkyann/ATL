\# Tag name: \[think]

\*\*Tag type:\*\* Flag Tag



\### 📝 Function

Forces the AI to activate its deep reasoning or chain-of-thought processing before generating the final response. It instructs the model to analyze constraints, evaluate potential edge cases, and think carefully to ensure higher accuracy and logical consistency.



\### ⚙️ Usage

Apply this tag for highly complex tasks, advanced logic problems, debugging tricky code, or strategic planning queries where a standard, instant AI response might overlook critical details.



\### 🎯 Example

\*\*User Prompt:\*\*

> `\[think]` Design a database schema for a high-traffic ride-sharing system.



\*\*AI Output:\*\*

\*Thinking Process:\*

\- Analyze scaling bottlenecks (rides table inserts vs. location tracking updates).

\- Determine isolation levels required for ride matching to prevent double-booking.

\- Compare SQL vs. NoSQL for geographic spatial indexing.

\[Final architecture and schema layout follows...]
