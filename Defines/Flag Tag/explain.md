\# Tag name: \[explain]

\*\*Tag type:\*\* Flag Tag



\### 📝 Function

Instructs the AI to focus entirely on explaining the concept, reasoning, or core logic of the query. It strips away or bypasses the final answer, result, or code output, focusing solely on the conceptual breakdown.



\### ⚙️ Usage

Apply this tag when you want to learn the "how" or "why" behind a solution without being distracted by the final calculated result or source code.



\### 🎯 Example

\*\*User Prompt:\*\*

> `\[explain]` How does Newton's third law of motion work?



\*\*AI Output:\*\*

Newton's third law states that forces always occur in matched pairs. When one object exerts a push or pull on another, the second object instantly pushes or pulls back with the exact same amount of force in the opposite direction. This happens because a force is not an isolated thing, but an interaction between two entities.
