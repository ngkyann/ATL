\# Tag name \[result]

Tag type Flag Tag



\### 📝 Function

Instructs the AI to output only the direct answer or final result. It completely strips away any step-by-step explanations, reasoning processes, formulas, or background information.



\### ⚙️ Usage

Apply this tag when you need a quick, no-nonsense answer (like a mathematical solution, a specific fact, or a yesno response) and want to save tokens and reading time.



\### 🎯 Example

User Prompt

&#x20;`\[result]` What is the square root of 144



AI Output

12
